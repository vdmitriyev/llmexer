### About

This project has been initiated to create and curate various datasets, including searches,
publications, metadata and LLM prompts, as well as data on different LLM experiments and their
parameters and results.

### Structure

* [experiment](experiment) - contains LLM experiments and their parameters
* [papers](papers) - contains PDF, txt and markdown of papers
* [searches](searches) - contains literature search params, results and metadata
* [analysis](analysis) - contains Jupyter Notebooks with analysis of searches and experiments
